# Dream Studio 2.0 — Product Vision

## 1. 제품 비전
**"학생은 아이디어를 만들고, AI는 구현하며, 학생은 다시 자유롭게 수정한다."**

Dream Studio 2.0은 코딩 경험이 전혀 없는 학생이 자신의 장래희망과 관심사를 한국어로 설명하면, AI가 맞춤형 웹사이트나 실제 플레이 가능한 2D 웹 게임을 새로 설계·구현하고, 학생이 **블록 속성 편집기**와 **AI 대화 수정(Diff 승인)**으로 작품을 끝까지 발전시킬 수 있는 **AI-Native No-Code Creative Platform**입니다.

## 2. 기존 템플릿 기반 도구(v1)와의 근본적 차이
- **템플릿/엔진 한계 제거**: 고정된 웹사이트 레이아웃이나 3개 게임 엔진 목록 안에서 값만 바꾸는 구조가 아니라, AI가 매 요청마다 HTML/CSS/JS와 편집 가능한 `ComponentGraph`를 새로 생성합니다.
- **이중 편집 패러다임**:
  - 단순 문구·색상·수치·게임 밸런스 조정 → `ComponentGraph` 기반 **즉시 블록 편집** (`postMessage` 무새로고침 반영)
  - 레이아웃 구조·신규 인터랙션·게임 규칙 추가 → **AI 대화 수정 + Diff 미리보기 + 사용자 명시적 승인**
- **안전과 정직성 최우선**:
  - 모든 생성 코드는 정적 문법·보안 검사를 통과해야 하며, `sandbox="allow-scripts"` (opaque origin, `allow-same-origin` 제외) + `CSP connect-src 'none'` 격리 환경에서만 실행됩니다.
  - 외부 AI API 키가 없을 때 모의 결과를 실제 AI 생성으로 위장하지 않고 `HTTP 503 AI_NOT_CONFIGURED`를 정직하게 반환합니다.

## 3. 대상 사용자
- **핵심 사용자**: 중·고등학생, 동아리 활동 학생, 진로 체험 참여 학생 (비개발자)
- **보조 사용자**: 진로·정보 담당 교사, 동아리 멘토
